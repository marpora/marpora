Marpora v0.4.0 brings an offline template library and a synchronized dual-screen Presenter to the lightweight Markdown editor.

## Download for macOS

- **Apple Silicon (M1 and newer):** `Marpora_0.4.0_aarch64.dmg`
- **Intel Mac:** `Marpora_0.4.0_x64.dmg`
- **Checksums:** `SHA256SUMS.txt`

Requires macOS 12 or later. These apps are ad-hoc signed, without Apple Developer ID signing or notarization. Intel packages are compiled and signature-checked; runtime testing on an Intel Mac is still needed. Windows/Linux packages are planned for a later release.

## Four original presentation packs

- **Orbit:** a keynote-style stage for product launches, with oversized typography, dark/light compositions and orbital line art. An original Marpora design, not an Apple-affiliated template.
- **Chalk:** a teaching rhythm of objectives, worked examples, prediction, discussion and step-by-step reveal.
- **Thesis:** research-oriented typography, equations, methodology, evidence and uncertainty.
- **Brief:** concise business narratives, trade-off comparisons, ownership and next steps.

Every pack includes seven sample slides and speaker notes. Use **Templates** to search, filter, preview every page, create a presentation, or apply a theme to an existing Markdown document. Theme changes are one undoable edit; other front matter, directives, comments, BOM and line endings remain intact.

Import CSS or a portable `.marpora.json` pack, save it in the local library and use it offline across restarts. Export packs to share them. Package metadata includes a version, author and license. Invalid CSS is rejected before installation; damaged stored packs cannot break the built-in themes. This version does not include an online shop, creator payments or remote automatic installation.

## Dual-screen Presenter

Choose a projection display for a fullscreen audience window. The original window becomes the presenter console with the current slide, next-slide preview, private notes, pause/resume/reset elapsed timer and thumbnail navigation. Both windows synchronize slide changes and fragment steps. Home/End jumps to the first/last slide; Esc ends the session.

Windowed rehearsal works on one monitor. Pane and thumbnail sizes can be dragged, reset with a double-click and remembered locally. Closing the audience window returns to editing. The projection display is rechecked during the session. Physical projectors, mixed-DPI monitor combinations and Intel runtime behavior still need wider hardware testing.

## Lightweight and source-preserving

The app continues to use the system WebView, with no bundled Chromium or Node.js. Templates use local fonts and CSS. Source/live editing, folders, tabs, HTML/PDF preview and export remain available. Presenting freezes the current buffer without saving or rewriting it. Standard Marp HTML speaker notes are recovered separately from the audience slides.

The tag-triggered GitHub Actions workflow builds both Mac installers, verifies signatures and disk images, and publishes them only after both architectures pass. SHA-256 checksums accompany the release.
