Marpora is a lightweight, local-first Markdown editor with live editing and Marp slide previews. This is an early macOS prototype.

## Downloads

- **Apple Silicon (M1 and newer):** `Marpora_0.3.1_aarch64.dmg`
- **Intel Mac:** `Marpora_0.3.1_x64.dmg`
- `SHA256SUMS.txt` contains checksums for both installers.

Requires macOS 12 or later. Both applications use ad-hoc signatures and are **not Developer ID signed or notarized**; macOS may require manual approval to open them. The Intel package has been built and signature-checked, but its runtime has not yet been tested on an Intel Mac.

## Highlights

- Live Markdown editing and source mode with preserved text, selection and undo.
- Folder browsing, multiple tabs, independent editing state and unsaved-draft recovery.
- Marp slide navigation, presentation fragments, speaker notes and custom themes.
- Read-only HTML/PDF previews and standalone HTML/PDF export.
- System WebKit/PDFKit slide PDF export on macOS, without bundled Chromium or Node.js.
- English/Chinese UI, system/light/dark appearance and accent colors.
- The folded M identity and desktop icons.

## Fixed in 0.3.1

- Clicking a live heading after slide breaks or tables now selects the displayed source line.
- Clicking the right preview gives arrow keys to slide navigation; clicking back into the editor restores caret movement.
- Complete macOS bundle signing and disk-image verification before artifact upload.

Markdown front matter, slide separators, custom directives, BOM and LF/CRLF remain source-preserving. PDF preview is currently canvas-only. Windows/Linux installers and a multi-window presenter view are planned; they are not included in this release.
