<h1 align="center">Marpora</h1>
<p align="center"><strong>Write locally. Present freely.</strong></p>
<p align="center">A lightweight, local-first Markdown editor with live editing and Marp slides.<br>macOS first, with Windows and Linux packaging in progress.</p>

Your writing and presentations belong in plain-text files. Marpora brings source-preserving Markdown editing and Marp slide previews into a small desktop workspace, using the system WebView instead of bundling Chromium.

- **Write:** live editing with a source-mode switch, local folders and multiple document tabs.
- **Present:** Marp slide previews, notes, fragments, custom themes and HTML/PDF workflows.
- **Make it yours:** English and Chinese, system appearance, light/dark themes and accent colors.

**[Explore the application →](https://github.com/marpora/marpora)**

Marpora is an early open-source prototype under the MIT license. Start with the repository for current capabilities, development instructions and platform limitations. A dedicated website and a reusable template catalog are planned.
